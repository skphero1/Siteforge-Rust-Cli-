# Writing Plans

Portable adaptation of obra/superpowers. Follow the repository AGENTS.md and the current user's instructions. [Original source](UPSTREAM.md) is preserved for attribution and comparison, not a second active workflow.

Read requirements and relevant files. Write a concise plan with goal, constraints, affected paths, ordered tasks, acceptance criteria, and exact verification commands. Include failure cases and dependency/service requirements. Keep tasks independently checkable and avoid speculative abstractions. Save substantial plans in docs/plans/; a short task may use an in-session plan. Check coverage against the request. Execute sequentially in the current session unless supported delegation is explicitly authorized. Do not require plugin names, an execution-mode menu, or a worktree. Continue authorized well-specified work without a redundant approval gate.

Upstream-only commands, hooks, browser scripts, and delegation are not prerequisites. See [provenance and adaptation policy](../UPSTREAM.md).
