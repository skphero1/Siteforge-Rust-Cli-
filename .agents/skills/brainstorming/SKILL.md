# Brainstorming

Portable adaptation of obra/superpowers. Follow the repository AGENTS.md and the current user's instructions. [Original source](UPSTREAM.md) is preserved for attribution and comparison, not a second active workflow.

Read the request and existing code first. Identify goals, constraints, acceptance criteria, and unknowns. For well-specified work, state a reasonable approach and proceed; do not require a new approval ceremony. For ambiguous high-impact decisions, explain the tradeoffs and obtain approval before dependent work. Keep design notes proportional to scope. Consider alternatives when they change cost, security, architecture, or user behavior. Record agreed decisions and move to [writing-plans](../writing-plans/SKILL.md) for multi-step work. Browser companions and subagent design checks are optional and require verified host support; text is sufficient.

Upstream-only commands, hooks, browser scripts, and delegation are not prerequisites. See [provenance and adaptation policy](../UPSTREAM.md).
